# Tractări Camioane București-Ilfov

Site vitrină static pentru servicii de tractări camioane, recuperare macara și vulcanizare mobilă în București-Ilfov.

Design generat cu Google Stitch, adaptat și populat cu date reale de contact.

## Rulare locală
Site static, fără build. Deschide `index.html` direct în browser, sau servește-l local:

```bash
npx serve .
```

## Deploy
Deploy pe Vercel ca site static (fără framework).
